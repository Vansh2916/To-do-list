# 📝 Modern Todo List App

A sleek, responsive, and feature-rich Todo List application built with **React**. This is my very first React project, crafted to learn component-based architecture, state management, and modern UI design!

🌐 **Live Website:** [https://to-do-list-sage-nu-94.vercel.app/](https://to-do-list-sage-nu-94.vercel.app/)

## ✨ Features

- **Task Management:** Add, complete, and delete tasks effortlessly.
- **Dynamic Progress Bar:** Real-time visual tracking of your completed tasks.
- **Smart Filtering:** Quickly switch between **All**, **Active**, and **Done** tasks.
- **Local Storage Persistence:** Your tasks stay saved right in your browser, even after a page refresh or restart.
- **Glassmorphism UI:** Clean, modern, and aesthetic design with smooth visual feedback.

## 🛠️ Tech Stack

- **React** (Functional Components, Hooks like `useState` & `useEffect`)
- **JavaScript (ES6+)**
- **CSS3** (Custom styling with modern variables and gradients)
